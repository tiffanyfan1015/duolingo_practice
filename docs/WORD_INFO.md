
# 日文與德文單字資料

版本：1.1

### 目前實作範圍

- 發音沿用 Duolingo 音訊，無法播放時嘗試裝置語音；不另外蒐集字典音檔。日文假名仍保留，德文 IPA 暫緩，不納入本階段的缺漏提醒。
- 正式網站已在打開單字詳情時逐字查詢字典 API；Duolingo 目前學到的意思放上方，字典義項、例句、語法及中文詞形另行呈現。其他意思、子義項與較少用義項保留，可展開閱讀；不需先人工審核或填寫資料。
- 字典義項以中文用字重疊作保守排序提示，未宣稱語義配對已確定；無重疊時顯示來源第一個非罕用義項。來源沒有的欄位不生成，未支援語言維持 Duolingo 資料。完整 P0／P1／P2 尚未全部覆蓋。
- 巢狀詞形表分別保留最內層資料表，避免將外層排版表攤平成文字。來源近義詞另列「相關詞語」並保留使用限制；來源片語與句子統稱「用法示例」。德文名詞的性別縮寫展開為中文與冠詞，變格類型附說明。目前未接入 CEFR／JLPT 等級資料，不能由強／弱變化判定程度。
- API 版先使用中文維基詞典，日文必要時透過 Jisho 核對原形。七天快取只保存查詢過的詞條；不自動下載完整字典。正式頁保留來源中文（可能含簡體），詞形標籤以中文顯示；Python 驗證工具另可使用 OpenCC 轉繁中，日文單字及例句保留原文。限流與查無資料分開顯示。
- 「採用」代表接受詞條／義項配對，不代表 P0 已完整、授權已核准或已發布到正式網站。缺漏提示只是欄位與部分詞性規則檢查，正確性及不適用情況仍需人工核對。
- 其他語言目前只呈現 Duolingo 回傳的基礎資料，不套用日文或德文的語法欄位。以下 P0／P1／P2 保留為完整內容目標。

## 1. 核心原則

1. **單字仍是一個單字**：一個詞條集中呈現該詞的意思、發音、變化、搭配及例句；不必把不同語法知識拆成多個單字。
2. **按義項解釋**：一字多義時，每個義項分開提供中文解釋、使用情境、搭配和例句；不同詞性可有各自的義項。
3. **先實用、後深入**：先提供理解及正確使用所需資訊；再補充近義詞、語源、構詞、語料等。
4. **只呈現適用欄位**：名詞不需要動詞變位表；日文與德文使用各自必要的語言專屬欄位。
5. **不確定就標註**：讀音、音調、詞源、例句、分級及詞頻等資訊要註明來源或不確定性，不猜測補齊。

優先級定義：**P0 必備**、**P1 推薦**、**P2 選配**。此處的「必備」指該資訊**適用於該詞性時**應提供。

| 優先級 | 資料 | 內容要求 |

| P0 | 繁體中文義項 | 分開列出常見意思，按實用程度排序，不只堆砌譯詞 |
| P0 | 例句 | 至少一個自然、符合義項的原文句子與繁中翻譯；重要義項各自配例句 |

**義項資料建議**：義項編號、繁中釋義、簡短用法說明、詞性（若適用）、語域、語法框架、搭配詞、例句與譯文。不要將只適用於某個義項的搭配錯誤套用到整個詞條。

## 3. 日文單字資料

### 3.1 P0 必備

- [ ] **標準表記及常見寫法**：漢字、假名，必要時列出其他常見表記（如 食べる／たべる）。
- [ ] **假名讀音**：必要時對應到各漢字表記；若有複數讀音，說明差異。
- [ ] **詞性及語法分類**：名詞、五段動詞、一段動詞、不規則動詞、い形容詞、な形容詞等。
- [ ] **自動詞／他動詞性質**：動詞適用時標註；部分詞存在多種用法時分別說明。
- [ ] **繁體中文義項**：區分不同意思，附簡要使用情境。
- [ ] **發音**：音檔（如可合法取得）、讀音來源；不要把羅馬字當成唯一發音資訊。
- [ ] **例句與繁中翻譯**：至少一個；可選加振假名以幫助閱讀。
- [ ] **基本語法搭配**：常見助詞和句型框架，例如 `N を食べる`。
- [ ] **必要詞形變化**：動詞提供普通形、ます形、て形、ない形、た形；形容詞提供適用的基本變化。

### 3.2 P1 推薦

- [ ] **東京式高低音調**：標明重音核／型號如 `[0]`、`[1]`，附音調系統及來源；存在變異時可列多種。
- [ ] **較完整的活用**：動詞可能、被動、使役、使役被動、命令、意向、條件等；形容詞否定、過去、條件等。
- [ ] **自他動詞配對**：例如 `開く（あく）` ↔ `開ける（あける）`，並搭配助詞對照。
- [ ] **常見搭配詞**：如 `約束を守る`、`約束を破る`。
- [ ] **敬語與禮貌表達**：如 `言う`、`おっしゃる`、`申す／申し上げる`，明確區分尊敬語、謙讓語等。
- [ ] **近義詞與語感比較**：如 `見る`、`観る`、`眺める`；說明用法差異，勿當作完全互換。
- [ ] **語域、地域、常見錯誤**：標註口語／書面語等及常見誤用。
- [ ] **JLPT 參考級別**：N5～N1 或無可靠分級；記載使用的第三方來源，避免宣稱存在官方完整分級詞表。

### 3.3 P2 選配

- [ ] 漢字音讀、訓讀、部件與相關複合詞（對該詞有幫助時）。
- [ ] 語源、構詞方式和詞義演變。
- [ ] 真實語料例句及可核對來源。
- [ ] 使用頻率、語境分布及統計來源。

### 3.4 日文示範詞條

**食べる（たべる）**

- **詞性**：動詞，一段動詞，他動詞。
- **主要義項**：吃、進食。
- **常見句型**：`N を食べる`（吃某物）。
- **主要詞形**：原形 `食べる`；ます形 `食べます`；て形 `食べて`；ない形 `食べない`；た形 `食べた`。
- **例句**：`毎朝、パンを食べます。`／每天早上吃麵包。
- **待依來源補充**：音調、發音音檔、可靠的 JLPT 參考分級。

**開く（あく）／開ける（あける）**

- **開く**：在「門開了」義項中作自動詞：`ドアが開く`。
- **開ける**：他動詞：`ドアを開ける`（把門打開）。
- **學習重點**：將助詞與自他動詞一起理解。

## 4. 德文單字資料

### 4.1 P0 必備

- [ ] **單字原形與詞性**：名詞大寫，保存正確德文拼寫和變體。
- [ ] **繁體中文義項**：區分各意思、語境及常見翻譯。
- [ ] **IPA、重音與發音**：如可取得音檔，記載語音及來源。
- [ ] **自然例句與繁中翻譯**：每個重要義項至少一例；句子應反映真實格或介系詞搭配。
- [ ] **名詞性別及冠詞**：`der`／`die`／`das`，必須和名詞一起記載。
- [ ] **名詞複數**：包含 Umlaut、零複數及其他不規則變化；不可只存推測的詞尾。
- [ ] **名詞重要變格**：至少註明不規則、弱變化及所有格單數等重要形式；可擴充完整四格表。
- [ ] **動詞主要形式**：Infinitiv、第三人稱單數現在式、Präteritum、Partizip II，以及 Perfekt 助動詞 `haben`／`sein`（適用時）。
- [ ] **動詞搭配及格支配**：例如 `helfen + Dativ`、`warten auf + Akkusativ`，依正確義項記錄。
- [ ] **形容詞基本資訊**：原形、比較級和最高級（適用時），以及典型修飾／敘述用法。

### 4.2 P1 推薦

- [ ] **完整名詞變格**：Nominativ、Akkusativ、Dativ、Genitiv，單數與複數；指出特別變化。
- [ ] **完整動詞變位**：人稱、數、時態、語氣；依字詞實際使用範圍提供。
- [ ] **動詞類型**：強、弱、混合變化；可分／不可分前綴；反身、及物、不及物等。
- [ ] **介系詞及格支配（Rektion）**：記錄固定結構及含義，例如 `teilnehmen an + Dativ`、`sich interessieren für + Akkusativ`。
- [ ] **形容詞詞尾變化**：強／弱／混合變化，在有需要時以表格呈現。
- [ ] **固定搭配與慣用語**：常見動名詞搭配、片語和例句。
- [ ] **複合詞拆解**：如 `Krankenhaus`（Kranken + Haus），標註構詞成分的真實語法身分，不只字面拆譯。
- [ ] **近義詞差異**：如 `wissen`／`kennen`，比較適用對象與句型。
- [ ] **地區與語域**：德國、奧地利、瑞士變體；正式、口語等。
- [ ] **CEFR 參考級別**：A1～C2 或無資料；必須標示來源，避免視為官方逐字等級。

### 4.3 P2 選配

- [ ] 語源、詞根、詞族及構詞規則。
- [ ] DWDS 類型的語料搭配分析及詞頻趨勢，附來源。
- [ ] 不同義項的詳細句法框架和語義限制。
- [ ] 學習者常見錯誤及正確／錯誤句型比較。

### 4.4 德文示範詞條

**der Tisch**

- **詞性／性別**：陽性名詞；冠詞 `der`。
- **主要義項**：桌子。
- **複數**：`die Tische`。
- **重要變格**：Genitiv 單數 `des Tisches`。
- **例句**：`Das Buch liegt auf dem Tisch.`／書放在桌上。
- **語法提示**：這句的 `auf` 表示靜態位置，使用 Dativ。

**sprechen**

- **詞性**：動詞。
- **主要義項**：說話、交談（其他義項應另列）。
- **主要形式**：第三人稱單數現在式 `spricht`；Präteritum `sprach`；Partizip II `gesprochen`；Perfekt 助動詞 `haben`。
- **變位示例**：`ich spreche`／`ich sprach`／`ich habe gesprochen`。
- **補充方向**：依不同義項列出 `mit + Dativ`、`über + Akkusativ` 等常見結構及例句。

**helfen**

- **詞性**：動詞。
- **主要義項**：幫助。
- **語法支配**：`jemandem helfen`（+ Dativ），不是直接用 Akkusativ。
- **例句**：`Ich helfe meiner Freundin.`／我幫助我的女性朋友。

## 5. 單字內容的完整度檢查

每次整理一個詞條時，請依序確認：

- [ ] 詞條原形、正確拼寫、讀音與詞性是否可靠？
- [ ] 是否區分主要義項，而非僅列多個中文近義譯詞？
- [ ] 是否提供至少一個**自然且正確**的例句和繁中翻譯？
- [ ] 是否記錄該語言及詞性不可省略的資訊（日文活用／助詞；德文冠詞／複數／變位／格支配）？
- [ ] 是否區分一般規則與例外、常見用法與特殊用法？
- [ ] 是否提供真正有助學習的搭配或易混淆詞，而非無關的百科式資訊？
- [ ] 不確定、地區變異、分級及來源限制是否清楚標記？
- [ ] 例句、音檔及第三方辭典內容是否具有適當的使用授權？
